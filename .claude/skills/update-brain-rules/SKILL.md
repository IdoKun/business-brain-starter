# Update my brain rules from the starter

The starter this brain was made from keeps improving. This brings the new parts in. **My own rules always win.**

1. Read the starter's changelog: https://github.com/IdoKun/business-brain-starter/blob/main/CHANGELOG.md
   (raw: https://raw.githubusercontent.com/IdoKun/business-brain-starter/main/CHANGELOG.md).
2. Read the last line of `wiki/log.md` that starts with `## [` and says `starter update` to see which version I already have. None → I have none of the changes yet.
3. For each newer entry, read the starter files it names (raw.githubusercontent.com/IdoKun/business-brain-starter/main/<path>) and compare them with mine.
4. Show me a short list: what's new, and what you'd add where. **Don't change anything yet.**
5. When I say yes:
   - Add only what's new. Keep my main-goal line, my instructions, my pages, my design and my skills as they are.
   - If a new rule goes against one in `wiki/my-instructions.md`, mine wins: skip it and tell me.
   - New skills: copy them into `.claude/skills/`. Never overwrite a skill I changed.
   - Never copy the example pages (the made-up yoga studio).
6. Add one line at the top of `wiki/log.md`: `## [YYYY-MM-DD] starter update | <version>: what was added`. Commit and push to `main`.
